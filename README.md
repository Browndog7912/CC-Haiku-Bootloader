# CC-Haiku-Bootloader
A Bootloader for Computer Craft, made for Haiku OS.

A Simple bootloader for Computer Craft

# Installation

There are three ways to install it they are mostly made to make it so you don't have to type as much

1. GitHub Shortlink
``wget run https://browndog7912.github.io/cc/hboot.lua``
2. Pastebin Link
``pastebin run ijkveHvW``
3. Github Raw Link
``wget run https://raw.githubusercontent.com/Browndog7912/CC-Haiku-Bootloader/refs/heads/main/installation.lua``

# Ussage 

To add or configure the boot loader edit the file in `/boot/bootloader.cfg`
